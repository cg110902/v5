书名：《编造前世日记曝光，女帝全员哭崩求原谅》
题材：玄幻脑洞 / 轮回曝光 / 白月光反转 / 追夫火葬场 / 情绪流爆款
核心主角：陆沉（太衍仙宗底层外门弟子，实为【九世轮回编造系统】宿主，心智冷静沉稳的绝对操盘手）

核心机制与外挂设定：
1. 【天道金榜·轮回天幕】：天地法则凝聚的轮回神石降世，每隔一段时间在九州天幕上全景投影“上古救世大能与被尘封的转世记忆”。
2. 【九世轮回编造系统】：陆沉可编造自己的“九世白月光救世记忆与绝笔日记”，并同步投影至天道金榜。
3. 【情绪具现法则】：天下人（尤其是当事女帝、女天骄、各宗巨擘）对前世画面的相信度越高、情绪波动越剧烈（痛悔、自责、道心崩溃、疯狂补偿），陆沉就能 100% 具现化前世编造的神级修为、无上仙骨与帝道法宝，并获得巨额情绪点数！
4. 【主角人设立场】：主角绝非真舔狗，而是绝对冷静的高维操盘者。主角借前世记忆收割全天下情绪值升级，面对痛哭倒贴的女帝保持绝对的疏离与高不可攀，让悔恨与遗憾化作最极致的情绪爽感。

第一世核心人物与曝光事件（首卷核心）：
- 目标人物：【冰魄女帝·南宫琉璃】（太衍仙宗开山祖师，如今君临东荒九万里的无上至尊）。
  - 当世人设：高居云端、冰冷绝情、断情绝爱、视众生为刍狗。天下皆传她生而神圣、天生至尊剑骨。
  - 编造第一世真相：八百年前，南宫琉璃天生寒髓枯竭，是个在破庙里快要冻死的残疾哑巴小女孩。少年陆沉为了让她活下去，以凡人之躯一步一叩首登上万剑绝峰，自挖天生剑骨换入她体内，替她生受了九道灭神天雷，致使自己双目失明、寿元耗尽，临终前默默在风雪深渊里写下绝笔日记……
  - 绝笔日记：“琉璃，不要哭。剑骨予你，你当立于九天之上。若有一日你君临天下，不必记我名姓，替我看一眼这世间的春暖花开即可……”

开局切入点与首章高光：
- 场景：太衍仙宗百年大典，全宗数万弟子恭迎冰魄女帝法身降临。外门管事仗势欺人，当众羞辱陆沉资质低下，正欲废除其微末修为、将其逐出山门。
- 爆发：九州天穹剧震，天道轮回金榜第一期降临，神光万里，天幕中轰然浮现出八百年前风雪破庙中少年自挖剑骨、换血救孤女的泣血真相！
- 反转高潮：不可一世、视众生为蝼蚁的冰魄女帝当场神魂战栗、道心轰然瓦解，在九万里山河与全宗门呆滞的目光中，泪崩跪倒在雪地里……

黄金锚点与创作红线：
1. [ANCHOR-001] 情绪拉扯拉满：女帝前期越是高不可攀、天下人越是看不起主角，天幕曝光时的反转打脸与悔恨就越撕心裂肺。
2. [ANCHOR-002] 主角逼格与心态超然：主角绝不卑躬屈膝，不搞廉价原谅。他喝茶看戏具现无敌底牌，任凭对方哭瞎双眼也绝不回头，主打“曾经你视我如草芥，如今我让你高攀不起”。
