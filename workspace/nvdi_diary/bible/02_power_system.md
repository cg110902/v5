## 二、 表现力与影响力具体标尺（Power & Impact Scale Anchors）

### 1. Tier 1（初始层）：淬体 / 炼气 / 筑基
- **能力表现 / 业务表现物理标尺**：掌碎坚硬青石，剑劈合抱木桩；奔行速度快逾奔马；筑基修士可短暂浮空离地三丈，挥剑斩断重甲。
- **社会 / 财富影响力标尺**：月领三五块下品灵石杂役俸禄，在宗门最底层为生存与资源挣扎，对管事和内门弟子躬身行礼。
- **能力 / 感知极限**：神念仅能覆盖周身三丈范围，受限于凡胎肉身，受刀剑重创仍会流血濒死。

### 2. Tier 2（中坚层）：金丹 / 元婴
- **能力表现 / 业务表现物理标尺**：御空飞行如雷霆破空，举手投足剑气斩断半座山丘；周身凝聚护体罡气，寻常万箭不能破防。
- **社会 / 财富影响力标尺**：掌控一座灵石矿脉或坊市巡查权，调配数十万下品灵石，在一方郡国受万众朝拜。
- **能力 / 感知极限**：神念覆盖数十里，能察觉草木微动；若遭同阶法宝围攻仍会护体破碎。

### 3. Tier 3（骨干层）：化神 / 炼虚 / 合体
- **能力表现 / 业务表现物理标尺**：引动百里天地异象，一剑断绝千丈巨江，翻掌之间平移整座雄伟峰峦；法则领域初步成型。
- **社会 / 财富影响力标尺**：坐镇顶级圣地主峰，掌控千万级极品资源流转，一言可定下辖数十凡俗皇朝更迭。
- **能力 / 感知极限**：神念笼罩千里方圆，可预判虚空波动；但尚未触及无上帝道极境。

### 4. Tier 4（巨擘层）：大乘 / 准帝
- **能力表现 / 业务表现物理标尺**：举手撕裂百里虚空，肉身横渡天外罡风雷海；大道法则外显凝聚法相，一念令山河倒流。
- **社会 / 财富影响力标尺**：圣地立世底蕴，闭关万年一出则天下震怖，决定圣地生死存亡与宗门道统兴衰。
- **能力 / 感知极限**：神念笼罩万里疆域，可捕捉一丝天地因果；但面对天道纪元大劫仍有陨落之虞。

### 5. Tier 5（极顶层）：无上女帝 / 至尊大帝
- **能力表现 / 业务表现物理标尺**：君临九万里疆域，一念崩灭域外星辰，滴血重生万物生机；执掌至高天道法则（如冰魄极道领域所过之处万物皆冻绝）。
- **社会 / 财富影响力标尺**：天下共尊，九天十地俯首称臣；一喜天地春回，一怒九州缟素。

## 三、 细分规则与差异化破局法则（System Rules）

1. **标准细分子阶划分**：
   - 每一大境界均细分为【初期 / 中期 / 后期 / 大圆满】四阶段；准帝至大帝之间存在【极道九劫】。
2. **越级破局与非凡表现的逻辑支点**：
   - **常规情况下的阶层壁垒**：修仙界大境界之间天堑难越，低阶修士面对高阶大能威压往往神魂战栗、动弹不得。
   - **主角能够实现突破/逆袭的核心支点**：陆沉凭借【九世轮回编造系统】直接具现前世极道道果、至尊剑骨与帝兵威能，调动的是凌驾于当世法则之上的高维因果本源，因此能在低境界时直接调动帝级剑气形成降维打击。
3. **一致性原则**：
   - 严禁境界与称号随意混淆漂移；
   - 破坏力描写严格锚定实物标尺，低阶绝不轰塌山峰，高阶绝不沦为摔杯互砍，保持前后战力自洽。
